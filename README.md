# Agent Mode 點數定價與單體經濟學計算機 

這是一個互動式點數定價與單體經濟學計算機。透過單一純靜態網頁，即可動態試算 AI Agent 工作流在不同運算成本、稅費折損與目標毛利率下的最低扣點定價、新使用者免費額度體驗次數（Aha Moment），以及定價階梯敏感度。

## ✨ 核心功能

* **動態參數即時連動**：支援調整基礎點數包售價、點數數量、新用戶免費額度、單次 Agent 綜合底層運算成本、目標毛利率、金流手續費率與營業稅率（VAT）。
* **精準微調控制（Precision Stepper）**：每個輸入欄位皆內建「▲ / ▼」微調按鈕，並提供右上角一鍵切換 `0.01` 或 `0.1` 的步進精度，方便進行細微的成本與費率敏感度測試。
* **雙軌定價對比分析**：
  * **名目毛利基準（問題 A）**：未計入稅費折損的理論最低扣點推導。
  * **實質淨營收基準（問題 B）**：納入營業稅（內含稅倒除）與第三方金流刷卡手續費後的實質淨入帳價值與商業建議定價（自動進位至 `5` 的倍數）。
* **Aha Moment 與算力曝險評估**：自動計算新用戶免費額度可完整執行的工作流次數、殘餘零頭點數（Residue Credits），以及單一未轉化免費用戶的最大算力成本曝險（Max CAC Compute Cost）。
* **零依賴單檔架構**：完全封裝於單一 `index.html` 檔案內（內嵌 Tailwind CSS CDN 與原生 JavaScript），無需後端伺服器或編譯環境，可直接部署於 GitHub Pages。

## 📐 核心計算公式說明

1. **點數票面基準價值 (Credit Benchmark)**
   $$\text{票面單點價值} = \frac{\text{點數包售價}}{\text{點數包內含點數}}$$

2. **有效淨營收保留率 (Net Revenue Retention Rate)**
   $$\text{保留率} = \frac{1}{1 + \text{營業稅率}} - \text{金流手續費率}$$

3. **實質毛利率達標之最低扣點數**
   $$\text{理論最低扣點} = \frac{\text{單次底層運算成本}}{(1 - \text{目標毛利率}) \times \text{票面單點價值} \times \text{有效淨營收保留率}}$$
   *商業建議定價則採 `CEILING(理論最低扣點, 5)` 進位至 5 的倍數，以符合 SaaS / AI 產品常見的定價心理慣例。*

# GenApe SEO Pillar Page Demo 

這是一個專為呈現 **GenApe 核心主文章（Pillar Page）SEO 內容架構與內部連結權重設計** 的互動式網頁線框原型（Wireframe）。

## ✨ 核心特色

* **雙視角一鍵切換**：
  * **🔍 SEO 結構標註視角**：清楚標示 `H1 / H2 / H3` 標題階層、`301 轉址承接錨點`，以及 `內部連結 ➔ 子文章 1 / 2` 的商業錨點文字。
  * **👁️ 讀者閱讀視角**：隱藏技術標籤，還原乾淨的商業文章排版與轉換漏斗介面。
* **完整內容骨架與目錄跳轉**：內建可點擊的快速目錄（Table of Contents）、2026 付費方案對比表、FAQ 折疊區塊，以及右側粘性（Sticky）`免費領取 200 點` 轉換卡片。
* **零依賴單檔部署**：純靜態 HTML 封裝（內嵌 Tailwind CSS CDN 與原生 JS），無需後端或建置環境。
